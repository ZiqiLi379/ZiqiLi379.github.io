## Personal webpage templates you can use

Here are a few beginner-friendly templates:

- **HTML5 UP** (free responsive templates): https://html5up.net/
- **Start Bootstrap** (portfolio/resume templates): https://startbootstrap.com/themes
- **Jekyll Themes** (great for GitHub Pages): https://jekyllthemes.io/free
- **Hugo Themes** (if you prefer Hugo): https://themes.gohugo.io/

## Quick recommendation

If you want the easiest GitHub Pages setup, start with a **Jekyll theme**:

1. Pick a theme from the Jekyll themes gallery.
2. Add the theme in your site config.
3. Update text, profile, and project sections with your own content.
